# Skills

A repository of agent skills to equip your agents with better taste, judgment, and capabilities.

## Install

```bash
npx skills@latest add tikiverse/skills
```

## Skills

- **[web-form-audit](./web-form-audit/SKILL.md)** — Design and review web forms that people actually finish. Covers layout, validation, accessibility, authentication, and mobile, distilled into decision rules an agent can follow. Heavily inspired by the work from LukeW.
