# Skills

A repository of agent skills to equip your agents with better taste, judgment, and capabilities.

## Install

```bash
npx skills@latest add tikiverse/skills
```

## Skills

- **[web-form-audit](./web-form-audit/SKILL.md)** — Design and review web forms that people actually finish. Covers layout, validation, accessibility, authentication, and mobile, distilled into decision rules an agent can follow. Heavily inspired by the work from LukeW.
- **[proposal-report](./proposal-report/SKILL.md)** — Generate a self-contained HTML proposal or recommendations report. Editorial serif design with a scored recommendation matrix, TOC sidebar, and prev/next pager. Interviews you first, then renders.
- **[status-report](./status-report/SKILL.md)** — Generate a self-contained HTML status or health report. RAG (red/amber/green) portfolio matrix, per-initiative milestone timelines, and decision callouts, built for an exec audience. Interviews you first, then renders.
- **[off-my-plate](./off-my-plate/SKILL.md)** — Close out any big task with a "let me take more off your plate" section: immediate follow-ups, automations worth setting up, and work to delegate to other people or agents.
